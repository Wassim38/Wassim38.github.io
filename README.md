## 🚀 Architecture & Technologies

- **Design & UI :**
  - **HTML5 Sémantique** & SEO optimisé (Balisage Schema.org `Person` JSON-LD, OpenGraph, Twitter Cards).
  - **CSS3 Moderne** : Custom Properties (thème sombre par défaut + bascule thème clair persistée en `localStorage`), Glassmorphism, animations GPU.
  - **Favicon Vectoriel Haute Définition** : `favicon.svg` + `favicon.png` 64x64.
  - **Logo Monogramme Vectoriel** : Badge SVG `<WL/>` ultra-net, sans coupure ni débordement.
- **Logique Client (Zero-dependency) :**
  - **Vanilla JavaScript (ES6+)** fluide, performant et autonome.
  - Système de modales interactives complètes (vidéo YouTube, diagrammes UML, métriques métier).
  - Filtrage dynamique des projets (*Entreprise & WMS*, *Web & APIs*, *Mobile Natif*, *Data & 3D*, *Équipe*).
  - Copie presse-papier en 1 clic avec notifications toast.
